Sales Performance Dashboard

Project Overview
This project presents an interactive Sales Performance Dashboard built using Excel.
The dashboard analyzes sales data and provides insights into revenue trends, customer segments, regional performance, and top-performing products.

Tools Used
1-Microsoft Excel / WPS
2-Pivot Tables
3-Pivot Charts
4-Data Cleaning & Formatting

Key Metrics
Total Revenue: 2,261,537
Monthly Sales Trend
Sales by Segment
Sales by Region
Top 5 Products by Sales

Dashboard Components
Monthly Sales Trend (Line Chart)
Sales by Segment (Column Chart)
Sales by Region (Bar Chart)
Top 5 Products by Sales (Horizontal Bar Chart)

Data Preparation
Cleaned missing values
Formatted dates
Standardized numeric fields
Removed duplicates
Used Pivot Tables for aggregation
